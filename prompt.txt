# Recorded prompts

## 2025-02-07 — Task and project management app

**Original request (restructured for clarity and efficiency):**

Build a professional task and project management web app with:

**Features**
- Dashboard: overview of all projects and tasks with key statistics
- Projects: create and manage projects with progress tracking
- Tasks: create, assign, and track tasks within projects
- Kanban: visual drag-and-drop task management by status
- Calendar: view tasks by due date

**Design**
- Clean, minimal aesthetic with ample white space
- Primary color: deep indigo (#4F46E5); soft grays; subtle status accents
- Typography: Inter; smooth transitions; card-based layouts
- Responsive, mobile-first

**Components to implement**
- Dashboard stats cards
- Project cards
- Task list items
- Kanban columns
- Sidebar navigation layout

**Tech**
- React functional components only
- TypeScript only

## 2025-02-07 — Mobile accessibility and compatibility

**Request (restructured):** Add mobile accessibility and compatibility.

**Scope:** Touch targets (44px min), safe-area insets, viewport/meta for mobile, reduced motion, focus-visible and ARIA for keyboard/screen readers, Kanban status dropdown for touch/keyboard, responsive calendar and layout.

## 2025-02-07 — ChatGPT integration for task composition

**Request (restructured):** Add ChatGPT integration so composition of new tasks is assisted by AI.

**Scope:** User-supplied OpenAI API key (Settings page, localStorage); “Compose with AI” in the new-task form: short prompt → suggest task → fill title and description (OpenAI gpt-4o-mini, JSON response). No backend; key used only from client for Suggest task.
